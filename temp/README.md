# Espacio temporal persistente

Esta carpeta está reservada para scripts Python y archivos de trabajo que se reutilizarán en tareas posteriores.

## Uso

- Guarda scripts reutilizables con nombres descriptivos, por ejemplo `importar_pois.py` o `verificar_geometrias.py`.
- Añade una breve cabecera al script que explique propósito, entradas, salidas y cómo ejecutarlo.
- Conserva solo archivos de trabajo útiles o que el equipo haya decidido reutilizar.

## No guardar aquí

- Secretos, credenciales, tokens, `.env` ni exportaciones con datos personales/ubicaciones reales.
- Dependencias Python (`.venv/`, `__pycache__/`) ni archivos generados pesados que puedan regenerarse.

Si un script pasa a ser parte estable del producto o despliegue, muévelo a una carpeta específica y documenta su uso.

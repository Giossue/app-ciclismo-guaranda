# Índice técnico

Lee [ARCHITECTURE.md](../../ARCHITECTURE.md) primero. Después abre solo la capa afectada:

1. `stack.md` para versiones y herramientas reales.
2. `backend.md`, `authentication.md` o `database.md` para Laravel, Fortify, políticas y persistencia.
3. `frontend.md` para React/Inertia, Wayfinder, shadcn y patrones móviles; carga solo el patrón necesario: `component-system.md`, `interface-design.md`, `data-tables.md`, `forms-and-workflows.md`, `feedback-and-states.md` o `navigation-responsive.md`.
4. `integrations.md` para OpenAI, elevación, mapas o APIs externas.
5. `deployment.md` para Docker, Dokploy, Android o CI.
6. `adr/` para cambios arquitectónicos duraderos.

Para detalle específico, usa `.codex/architecture/` y las reglas del router de `AGENTS.md`.

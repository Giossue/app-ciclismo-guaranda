# Especificaciones de funcionalidades

Antes de iniciar una funcionalidad no trivial, identifica el plan de fase en `.codex/plans/` o crea una especificación breve aquí con:

1. Problema y usuario afectado.
2. Flujo y criterios de aceptación comprobables.
3. Permisos, datos, offline y fallos esperados.
4. Decisiones o tradeoffs que deben persistir.

Usa `_template/` como base. No dupliques una especificación de fase que ya exista; enlázala.

# Glosario

| Término | Significado en Guaranda Go |
| --- | --- |
| Ruta oficial | Recorrido creado, versionado y publicado por administración. |
| POI | Punto de interés asociado o cercano a una ruta. |
| Recorrido | Ejecución GPS de una ruta por un ciclista. |
| Ruta válida | Ruta con avance registrado de al menos 90 %. |
| Incidencia activa | Incidencia en revisión, visible para alertar al ciclista. |
| Paquete offline | Datos de ruta descargados y versionados para uso sin red. |
| Cola de sincronización | Operaciones locales pendientes de envío al servidor. |
| Asistente | Agente externo ejecutado por n8n; no es una IA embebida en la app. |

## Regla de lenguaje

La UI usa español y lenguaje de cicloturismo. No expone nombres internos como Laravel, webhook, n8n, PostGIS, tokens, IDs ni estados de moderación cuando no son relevantes para el ciclista.

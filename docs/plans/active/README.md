# Trabajo activo

Los planes activos de Guaranda Go se mantienen en `.codex/plans/` y su estado en `.codex/progress/` para conservar el historial existente.

Antes de un cambio no trivial, revisa:

1. `.codex/progress/current_status.md`
2. `.codex/progress/phases.md`
3. El plan de fase o bugfix correspondiente.

Crea aquí un plan transversal solo si no pertenece a una fase y requiere varias sesiones.
